# Deployment Guide

This project has two deployable parts:

- `backend`: FastAPI API, best deployed on Render.
- `frontend`: Vite React app, best deployed on Vercel.

Deploy the backend first, then deploy the frontend, then update backend CORS with the final frontend URL.

## 1. Prepare Accounts

1. Create or log in to GitHub.
2. Push this project to a GitHub repository.
3. Create or log in to MongoDB Atlas: https://www.mongodb.com/atlas
4. Create or log in to Render: https://render.com
5. Create or log in to Vercel: https://vercel.com
6. Create or open your Google AI Studio API key page: https://aistudio.google.com/app/apikey

## 2. Create MongoDB Atlas Database

1. Open MongoDB Atlas.
2. Click `New Project` if you do not already have one.
3. Name it anything, for example `AI Course Generator`.
4. Click `Build a Database`.
5. Choose a free/shared cluster if available.
6. Choose a nearby cloud region.
7. Create the cluster.
8. Go to `Database Access`.
9. Click `Add New Database User`.
10. Create a username and password.
11. Save the password somewhere safe for the next few minutes.
12. Give the user read/write access.
13. Go to `Network Access`.
14. Click `Add IP Address`.
15. For easiest deployment, choose `Allow Access From Anywhere`.
16. Go back to `Database`.
17. Click `Connect`.
18. Choose `Drivers`.
19. Copy the connection string.
20. Replace `<password>` with your database user password.
21. Keep this final value ready as `MONGODB_URL`.

## 3. Get Gemini API Key

1. Open Google AI Studio.
2. Click `Create API key`.
3. Copy the key.
4. Keep it ready as `GEMINI_API_KEY`.

## 4. Deploy Backend on Render

1. Open Render.
2. Click `New`.
3. Choose `Blueprint`.
4. Connect your GitHub repository.
5. Render should detect `render.yaml`.
6. Click through the setup until you reach environment variables.
7. Set `MONGODB_URL` to your MongoDB Atlas connection string.
8. Set `GEMINI_API_KEY` to your Gemini key.
9. Leave `SECRET_KEY` generated by Render, or set your own long random value.
10. Set `BACKEND_CORS_ORIGINS` temporarily to:

```text
http://localhost:5173
```

11. Deploy the service.
12. Wait until Render shows the service is live.
13. Copy your backend URL, for example:

```text
https://ai-course-generator-api.onrender.com
```

14. Open this in your browser:

```text
https://your-render-backend.onrender.com/health
```

15. Confirm it shows:

```json
{"status":"ok"}
```

## 5. Deploy Frontend on Vercel

1. Open Vercel.
2. Click `Add New`.
3. Choose `Project`.
4. Import the same GitHub repository.
5. In project settings, set `Root Directory` to:

```text
frontend
```

6. Keep the framework preset as `Vite`.
7. Confirm build command is:

```text
npm run build
```

8. Confirm output directory is:

```text
dist
```

9. Add this environment variable:

```text
VITE_API_BASE_URL=https://your-render-backend.onrender.com/api
```

10. Replace `https://your-render-backend.onrender.com` with your real Render backend URL.
11. Click `Deploy`.
12. Wait until Vercel finishes.
13. Copy your Vercel frontend URL, for example:

```text
https://your-project.vercel.app
```

## 6. Connect Frontend to Backend CORS

1. Go back to Render.
2. Open your backend service.
3. Go to `Environment`.
4. Find `BACKEND_CORS_ORIGINS`.
5. Set it to your real Vercel URL:

```text
https://your-project.vercel.app
```

6. If you also want local development to keep working, use both values separated by a comma:

```text
http://localhost:5173,https://your-project.vercel.app
```

7. Save changes.
8. Redeploy the backend service.

## 7. Final Test

1. Open your Vercel frontend URL.
2. Create a new account.
3. Log in.
4. Generate a small beginner course.
5. Open the generated course.
6. Open a lesson.
7. Mark a lesson complete.
8. Refresh the page and confirm your course/progress is still there.

## Local Production Checks

Run these before pushing changes:

```bash
cd frontend
npm run build
```

```bash
cd backend
pip install -r requirements.txt
python -c "from app.main import app; print(app.title)"
```

## Required Environment Variables

Backend:

```text
MONGODB_URL=mongodb+srv://USER:PASSWORD@CLUSTER.mongodb.net/?retryWrites=true&w=majority
DATABASE_NAME=course_generator_db
GEMINI_API_KEY=your-gemini-api-key
SECRET_KEY=change-me-to-a-long-random-secret
BACKEND_CORS_ORIGINS=https://your-project.vercel.app
```

Frontend:

```text
VITE_API_BASE_URL=https://your-render-backend.onrender.com/api
```
